Policy rules

These rules define the intended access model for the subscription rollout.

  • FreeAvailable to signed-in candidates without a paid plan.
  • PaidRequires a valid subscription entitlement or an authorized admin grant.
  • InheritUses the parent folder’s policy. A test can override its folder by choosing Free or Paid.
  • Default for new contentPaid. Existing content is backfilled to Free to avoid unexpectedly locking current users.
